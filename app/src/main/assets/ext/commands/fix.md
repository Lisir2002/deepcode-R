---
name: fix
description: 分析并修复最近一次构建/命令失败，给出根因、最小改动与验证结果
argument-hint: 可选：报错关键词或目标文件
---
请定位当前工作区最近一次失败（构建报错 / 命令非零退出 / 单元测试失败），并完成修复：
1. 若用户提供了具体报错或文件，优先围绕它展开；否则先检查最近的构建/测试输出，找到首个报错点；
2. 定位根因（不要只看表象），给出最小改动方案，说明为什么这样改；
3. 实施修复，只动必要的文件；
4. 运行对应验证命令（编译/单测）确认通过，给出验证输出摘要；
5. 最后用中文总结：根因、改动文件与内容、验证结果。
