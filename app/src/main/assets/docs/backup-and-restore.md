# 备份与还原 (Backup)

进入「设置」->「备份与还原」，加密导出/导入应用配置、聊天历史与凭据。

## 1. 导出备份
*   **选择导出数据**：勾选要导出的数据范围，包括 AI 提供商、Git 凭据、远程连接与挂载、聊天历史、MCP 服务器、授权规则、应用设置。
*   **设置导出口令**：留空则输出明文 tar.gz；填写则用口令加密（AES-GCM）。
*   导出格式为 tar.gz 压缩包，含 API Key 等凭据，通过系统文件选择器保存到指定位置。

## 2. 导入备份
*   从备份文件还原数据，合并方式导入，不清除现有数据。
*   需输入对应口令；备份未加密则留空。
*   导入完成后展示已还原数据汇总（提供商、Git 凭据、远程连接、远程挂载、聊天会话、聊天消息、待办项、MCP 服务器、全局授权规则等数量）。

## 3. 历史对话"消失"怎么办（包名变更 / 混装变体）
App 的数据按**包名**在系统内隔离，以下情况会表现为"历史对话被清空，只剩一条会话"：

*   **包名（applicationId）变更**：历史上包名从 `com.aicodeeditor` → `com.deep.rcode` → `com.R.codecore` 变更过三次。每次变更是完全不同的 App，新包名全新安装，旧包的历史对话**不会自动迁移**。
*   **混装 Debug / Release 包**：Debug 版包名是 `com.R.codecore.debug`，Release 版是 `com.R.codecore`，两者数据目录互不相通。在「关于」页可看到当前安装的「构建变体」与「包名」。

**找回方法**：若在「备份与还原」页顶部看到「检测到旧版本数据」提示（说明旧版本应用仍安装在本机且签名相同），请按以下步骤恢复：
1. 打开**旧版本**应用 → 「设置」→「备份与还原」→「导出备份」，勾选「聊天历史」并保存。
2. 打开**本版本**应用 → 「设置」→「备份与还原」→「导入备份」，选择刚才的备份文件。
3. 导入完成后历史对话即合并恢复。

> 提醒：升级时应始终安装**同一包名**的 Release 版 APK，且不要与 Debug 版混装，以免再次出现数据隔离。

## 4. 数据保全（自动备份与数据丢失提示）
为防止升级或异常导致历史数据丢失，应用内置了**三层数据保全防线**：

*   **升级前自动备份**：检测到应用升级（版本号变大）时，自动把聊天历史、凭据、设置等**全量数据**备份到本机私有目录（仅本应用可读，保存最近 7 份，超出自动清理）。升级完成后历史数据随时可回滚。
*   **本机自动备份卡片**：「备份与还原」页顶部展示上次自动备份时间与备份份数，可点击「立即备份到本机」手动创建一份。
*   **数据丢失检测**：应用启动时会检查本包名下数据是否异常为空。若检测到数据疑似丢失（例如包名变更导致的数据隔离，或数据被异常清空），「备份与还原」页会显示红色告警横幅，并提供「从最近备份恢复」入口一键还原。

> 说明：自动备份为无口令的明文，仅存于应用私有目录（其他 App 不可读）。如需跨设备保存，请使用「导出备份」功能自行加密保存。
> 提示：若您是有意清空聊天记录（例如手动删除所有会话），数据丢失告警可忽略，不会影响使用。

## 5. 注意事项
*   口令丢失则加密备份无法恢复。
*   导入后应用内仍按现状明文存储。
