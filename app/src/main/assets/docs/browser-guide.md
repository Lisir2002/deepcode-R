# 内置服务浏览器 (Browser)

顶栏右侧「浏览器」入口进入内置服务浏览器页。浏览器与 AI 共享同一个浏览会话与登录态：你在浏览器里登录的账号，AI 可自动复用；AI 浏览/操作页面时，浏览器页实时可见。

## 1. 地址栏与导航
*   **地址栏**：显示当前页面 URL，可直接输入网址（自动补全 `https://`）或搜索关键词（默认走搜索引擎），回车后导航。
*   **前进/后退**：地址栏左侧，按历史栈切换。
*   **刷新**：地址栏右侧，重新加载当前页。
*   **标签栏**：多标签切换，`+` 新建标签，标签页右上角 `×` 关闭。

## 2. 「更多」菜单
点击地址栏右侧「⋮」（更多）菜单，提供以下功能：

### 浏览与分享
*   **分享**：通过系统分享面板把当前页链接分享给其它应用。
*   **复制链接**：复制当前页 URL 到剪贴板。
*   **收藏本页 / 取消收藏**：把当前页加入收藏夹（或移除）。
*   **页内查找**：打开查找条，输入关键词实时高亮匹配，支持「上一个 / 下一个」切换，关闭后清除高亮。

### 历史记录
*   **历史记录**：打开历史面板，按时间倒序列出最近访问（同 URL 自动去重），点击条目回跳；可「清空」全部历史。
*   **无痕模式**：会话级开关。开启后当前会话不写入历史、不保留 Cookie（切换时清空 Cookie 与缓存），关闭后恢复正常记录。无痕期间访问的页面不会出现在历史记录中。

### 收藏夹
*   **收藏夹**：打开收藏夹面板，列出全部书签（标题 + 网址），点击打开，左滑或按钮可删除。

### 内容管理
*   **下载管理**：列出浏览器下载任务（文件名 / 大小 / 状态），支持「打开」已下载文件（经系统文件选择器）、「重试」失败任务、「清除」列表。
*   **凭据管理**：列出已保存的站点登录凭据（主机 + 用户名），密码默认打码，点击「眼睛」图标显示明文，删除需确认。

## 3. 新标签页 / 主页
当前标签无打开页面时展示**主页**：顶部搜索框（可搜索或输入网址）、「最近访问」列表（快捷回跳）、「收藏夹」快捷入口（点击即打开）。

## 4. 适配与显示
*   **桌面版切换**：按桌面版 User-Agent 重新加载当前页（部分 PC 站以桌面版展示），再点一次切回手机版。
*   **缩放控制**：调整页面文字缩放（50%–200% 步进），支持「重置」恢复默认。

## 5. 登录与安全
*   页面弹出登录表单时，浏览器提供**凭据代填**：输入用户名/密码后可选择「记住」，后续同站点自动填充（凭据加密存储于本机 Keystore）。
*   需要输入验证码 / 支付 / 二次认证等场景，AI 会让出控制权，由你手动完成后再继续。
