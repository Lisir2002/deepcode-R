# 容器镜像 (Container)

进入「设置」->「容器镜像」，管理 AI 命令执行的后端。列表单选切换当前生效的 profile，后端分两类：**本地容器镜像**（PRoot）与**远程 SSH**。两者必居其一，选中即按该后端执行命令、读写文件、运行终端。

## 1. 本地容器镜像

通过 PRoot 在手机本地运行一个 Linux rootfs，AI 的命令、文件、终端都在这个容器内执行。适合无需远程服务器、离线或要直接操作手机本地文件的场景。

### 内置镜像
默认提供内置 Alpine 镜像，shell 路径自动选择（bash/sh），无需配置。

> **首次使用需先在终端页面完成初始化**：容器首次使用（解压 rootfs、安装基础工具）只在进入**终端页面**时自动触发。在此之前，Git 页、AI 的 Bash 工具、依赖本地容器的 MCP 命令会直接提示「请先进入终端页面完成初始化」，而不会自动初始化，避免多入口并发初始化互相打断。

### 自定义镜像
点击右上角「+」号选择「本地镜像」类型，新建自定义 profile：
*   **名称**：镜像配置别名。
*   **shell 路径**：如 `/bin/sh`、`/bin/bash`。
*   **额外绑定**：空格分隔，如 `/sdcard:/mnt`，把宿主目录挂进容器。
*   **额外 proot 参数**：空格分隔。
*   **镜像文件**：选择 tar.gz / tgz / tar.xz / txz 格式的 rootfs 镜像文件。

自定义镜像只保证能起 shell 执行命令，不 provision、不接管镜像源——所需工具由用户自行在容器内安装。

## 2. 远程 SSH

不使用本地容器，而是连接一台远程 SSH 服务器作为执行后端：命令走 SSH exec channel，文件读写走 exec channel（cat/printf/base64），终端交互走 SSH shell channel。适合远程服务器上已有完整工具链、或想让 AI 直接操作远程项目的场景。

### 前置：配置 SFTP 通道
远程 SSH 复用「远程服务器」页（详见 `remote-servers.md`）里配置的 **SFTP** 通道的连接信息（主机、端口、用户名、密码）。因此先在那里建好一个 SFTP 连接通道；FTP 与本地通道不支持 SSH exec，不会出现在可选列表中。

### 新建远程 SSH 镜像
点击右上角「+」号选择「远程 SSH」类型：
*   **名称**：镜像配置别名。
*   **SSH 连接通道**：下拉选择一个已配置的 SFTP 通道。若列表为空，会提示先去「远程服务器」页配置。
*   **远程工作区路径**：远程服务器上的目录，AI 的 `~/workspace` 将映射到此路径。选中通道时会自动填一个默认值（如 `/home/<用户名>/workspace`），可手动修改。

选中该远程 SSH 镜像后即切换为远程模式，命令与文件操作直接在远程服务器上执行，不再使用本地容器镜像。

### 连接行为
*   **自动连接**：App 启动时若当前是远程 SSH 模式，会在后台自动连接；连接失败不阻塞 UI，首次命令时会再触发重试。
*   **保活与自动重连**：连接建立后启用 SSH 心跳（每 30 秒）防止空闲断连；连接断开时由监督协程自动重连（指数退避 5 秒起、最长 30 秒），App 回到前台也会立即触发一次重连。重连成功后会重新加载工作区、并重新同步内置文档到远程。
*   **连接状态指示**：远程模式下对话顶部栏会显示 `SSH：已连接 / 连接中 / 连接失败 / 未连接` 状态，未连接时消息区显示等待提示，避免空白。
*   **文档同步**：连接成功后会把内置的 `~/.deepcode/docs/` 文档同步到远程服务器同名目录，使远程模式下 AI 也能查阅这些设置说明文档。

### 认证方式
当前远程 SSH 执行后端复用 SFTP 通道的**密码**认证。私钥认证在底层已支持，但 UI 暂未提供选择入口。

## 3. 编辑与删除
所有自定义镜像（本地与远程 SSH）均可编辑上述字段、可删除。删除本地镜像会一并清理其 rootfs 目录；删除远程 SSH 镜像只删配置，不影响远程服务器上的数据。内置 Alpine 不受影响、不可删。
