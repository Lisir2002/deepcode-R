## 1. 顶部标题栏 (ChatHeader)
App 最顶部是聊天页标题栏，包含：
*   **菜单按钮**（左上）：打开侧边抽屉，管理会话列表、新建会话。
*   **会话标题 + 模型名**：当前会话名称（上）与当前启用的模型名称（下）上下排列。
*   **新建会话**：开始一个新的聊天。
*   **Git 入口**：跳转到 Git 版本管理页。
*   **终端入口**：跳转到终端页。
*   **SSH 连接状态（仅远程模式）**：标题栏下方一行，左侧显示 SSH 连接状态指示（圆点 + 文字：已连接 / 连接中… / 连接失败 / 未连接），右侧显示当前会话的 token 累计统计（↑输入 ↓输出）。仅远程 SSH 模式下显示，本地模式不显示。
*   **远程连接占位提示**：远程模式下若连接未就绪，消息区显示占位提示（如「正在连接远程服务器…」「远程服务器连接失败」），避免空白。

## 1.1 侧边栏 (ChatDrawer)
点击标题栏左上角菜单按钮（或从屏幕左缘右滑）打开侧边抽屉：
*   **新建会话**：顶部按钮，点击创建新会话。
*   **历史记录**：会话列表，短按选中并切换到该会话；**长按弹出操作菜单**（重命名 / 删除）：
    *   **重命名**：弹出对话框输入新名称，确认后更新会话标题，不影响列表顺序。
    *   **删除**：弹出确认框，确认后删除该会话及其所有消息。
*   **设置**：底部入口，点击跳转到设置页。

## 2. 聊天输入框下方工具栏
输入框与工具栏整合在底部一个胶囊状悬浮条中（圆角 + 阴影，键盘弹出时自动上浮）。工具栏一行从左到右依次为：
*   **模式按钮**：点击在 BUILD → PLAN → AUTO 间循环切换（详见下节）。
*   **模型按钮**：显示当前启用的 AI 模型，点击可快速切换模型或跳转到设置管理提供商。
*   **工作区按钮**：显示当前工作区名称，点击弹出工作区管理面板（底部弹窗）：
    *   列出所有已创建的工作区，点击切换。若当前有正在运行的 AI 会话或终端标签，会弹出确认框提示切换会停止它们。
    *   可新建工作区（输入名称创建）。
    *   可删除已有工作区。
    *   工作区是 AI 操作的代码项目根目录，每个工作区对应手机上的一个独立文件夹，AI 的代码读写和命令执行都被沙盒隔离在当前工作区内。
*   **更多选项按钮**（⋯）：展开/收起收纳行，收纳了低频操作按钮：
    *   **思考强度**（深度思考）：调节当前会话的 Reasoning 强度（低/中/高），AI 忙碌时不可用。
    *   **技能**：打开对话技能面板，管理当前对话生效的技能。
*   **添加附件按钮**（＋）：弹出附件面板，可选择上传文件、上传图片或拍照。AI 忙碌时不可用。
*   **发送按钮**：发送当前输入；生成中变为停止按钮。
*   上传的附件会以预览卡形式显示在输入框上方，可移除后再发送。
*   **斜杠命令**：在输入框输入 `/` 会弹出命令菜单，支持以下命令：
    *   `/status`：查看当前会话状态（token 用量、模型、模式等），结果以 AI 气泡输出。
    *   `/compress`：手动触发当前会话的上下文压缩。
    *   命令在 AI 忙碌时会进入待发送队列，空闲时自动执行；命令文本会作为用户消息显示在对话中，并进入对话上下文。

### 2.1 消息队列
AI 工作时输入框仍然可用，输入后回车（或点击发送键前的回车操作）不会打断当前任务，而是将消息加入**待发送队列**：
*   队列面板显示在输入框上方（样式与斜杠命令菜单一致），列出排队消息的序号与摘要，数量显示在面板标题。
*   当前一轮 AI 任务结束后，队列中的下一条会自动发送执行；排队多条时按顺序依次执行。
*   点「停止」按钮会跳过当前轮任务，立即执行队列中的下一条。
*   排队内容过多时，面板内部可滚动；每条消息右侧的 × 按钮可将其从队列移除。
*   斜杠命令同样排队：AI 忙时发送 `/status`、`/compress` 会先进入队列，轮到执行时命令会作为用户消息显示并进入对话上下文。
*   队列仅保存在内存中：切换工作区或进程被杀时会清空。

## 3. 核心模式切换 (Plan / Build / Auto)
工具栏左侧的模式按钮点击在三种模式间循环切换：**BUILD → PLAN → AUTO → BUILD**。
*   **BUILD (构建模式)**：全功能模式，解锁写权限。AI 可以帮用户写文件、修改代码以及运行构建命令。
*   **PLAN (计划模式)**：进入此模式后，系统物理级锁死 AI 的写操作权限。AI 只能进行代码阅读、检索和方案构思，绝不会修改任何文件。
*   **AUTO (自动模式)**：权限全放行模式。所有工具调用（写文件、执行命令、终端操作等）自动批准，不弹权限确认窗。仅灾难性删除（`rm` 根目录/系统目录等）仍被拦截。该模式权限极大，适合用户已明确知晓风险、希望 AI 全自动完成批量任务的场景。
*   *提示：除了用户手动点按钮切换，AI 自己在规划清晰后，也可以通过调用 `switchMode` 工具向用户发送切换模式的请求，用户在界面上一键批准即可。注意：AUTO 模式只能由用户在界面上手动进入，AI 无法通过工具切换到 AUTO；但处于 AUTO 模式时，AI 可通过 `switchMode` 切换到 PLAN 模式退出自动模式（这是 AI 退出 AUTO 的唯一路径）。*

## 4. 设置首页菜单项
“设置”首页以卡片列表呈现各二级入口，自上而下依次为：
*   **模型服务商**：显示已添加数量与当前启用提供商；进入「模型服务商」二级页管理（详见 providers-and-models.md）。
*   **默认模型**：进入「默认模型」二级页，管理识图模型等默认偏好；点击其中的「识图模型」项可直接弹出模型选择弹窗。
*   **工具服务**：显示已配置数量与已连接数；进入「工具服务」二级页（详见 mcp-and-skills.md）。
*   **容器镜像**：显示当前镜像 profile 名（默认“内置 Alpine”）；进入「容器镜像」二级页（详见 container-image.md）。该页以列表单选切换当前生效的 profile，选中本地镜像即走 PRoot 容器，选中远程 SSH 镜像即连接远程服务器执行命令。远程模式下命令执行走 SSH exec channel、文件读写走 SFTP，MCP stdio server 仍走本地 PRoot。
*   **运行日志**：显示当前日志等级名；进入「运行日志」二级页查看/筛选最近日志、切换日志等级。
*   **工具授权**：显示已保存授权规则条数；进入「工具授权」二级页。
*   **远程工作区**：管理 SFTP / FTP 工作区同步；进入「远程工作区」二级页（详见 remote-servers.md）。
*   **外观主题**：点击弹出窗口选择（自动/深色/浅色）。
*   **语言**：点击弹出窗口选择（跟随系统/语言列表）。
*   **后台运行保活**：首页内联开关，开启后显示前台通知避免后台被杀。
*   **备份与还原**：加密导出/导入配置、聊天历史与凭据；进入「备份与还原」二级页（详见 backup-and-restore.md）。
*   **关于应用**：版本检查 · GitHub · 许可证；进入「关于应用」二级页。

## 5. 外观主题设置
“设置”首页点击「外观主题」卡片会弹出底部窗口进行选择：
*   **外观主题**：
    *   **跟随系统**：跟随系统当前的明暗主题。
    *   **深色**：固定使用深色主题。
    *   **浅色**：固定使用浅色主题。
*   选择后立即生效并持久化保存。

## 6. 关于 (About)
“设置”首页「关于应用」入口（图标为信息圆圈）。这是一个纯展示型页面，无任何持久化设置，点击进入后展示下列信息：
*   **应用信息**：顶部卡片左侧显示 App 图标，右上为应用名 `R-CodeCore`，右下为一句简介。
*   **版本（点击检查更新）**：单独一行卡片，显示当前版本号 `v<versionName>`（通过系统 PackageManager 读取，即对外发布版本，与 git tag `v<versionName>` 一致）。点击该行会自动通过 GitHub API `https://api.github.com/repos/Lisir2002/deepcode-R/releases/latest` 查询最新 Release 的 tag，与当前版本号比对：
    *   相等 → 弹窗提示「已经是最新版本」。
    *   不同 → 弹窗「发现新版本 vX」，点击「前往下载」用浏览器打开 GitHub Releases 页面获取最新 APK。
    *   网络失败或解析失败 → 弹窗提示「检查失败」并给出错误信息。
*   **构建变体 / 包名**：应用信息卡片内展示「构建变体」（Release 版 / Debug 版）与「包名」（如 `com.R.codecore` 或 Debug 版 `com.R.codecore.debug`）。App 数据按包名隔离，混装 Debug/Release 包或包名变更都会导致历史对话不可见（详见 backup-and-restore.md 第 3 节）。
*   **GitHub 仓库**：点击用系统浏览器打开本项目源码仓库 `https://github.com/Lisir2002/deepcode-R`。
*   **开源许可证**：本项目使用 **GPL-3.0**，点击用浏览器打开完整 LICENSE 文件。
