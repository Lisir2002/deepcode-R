## 6. 推进规则

1. **只记录进度**：本文档不写详细设计（见各设计文档），只维护状态、前后依赖、完成验证。
2. **每完成一项**：更新本文档状态（📝 → ✅）+ 在 `design-master-plan-design.md` §6 完成记录勾选。
3. **新设计任务**：先在 `design-master-plan-design.md` §4 登记，再补充本文档进度行。
4. **跳级禁止**：前置未完成（⬜/📝）不启动后置任务的实施；设计缺口先补设计再实施。
5. **模型工作前**：先读本文档 §2/§3/§4 定位前后进度，再读对应设计文档的详细章节。
